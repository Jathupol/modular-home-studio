# Dream Home Creator

สร้างเว็บไซต์สำหรับธุรกิจ “บ้านน็อคดาวน์ / บ้านสำเร็จรูป” ของฉัน โดยมีเป้าหมายหลักคือ แสดงแบบบ้านให้ลูกค้าเลือก ดูรายละเอียด และส่งคำขอสั่งจอง/ขอใบเสนอราคาได้ง่าย

ให้ออกแบบเว็บไซต์โดยใช้เว็บไซต์ตัวอย่างนี้เป็น Reference ด้านโครงสร้างและประสบการณ์ใช้งาน:
https://www.container.co.th/knockdown/

สำคัญ: ห้ามคัดลอกข้อความ รูปภาพ โลโก้ สี หรือองค์ประกอบที่มีลิขสิทธิ์จากเว็บไซต์ตัวอย่าง ให้สร้างดีไซน์ใหม่ที่เป็นเอกลักษณ์ของแบรนด์ฉันเอง แต่สามารถนำแนวคิดเรื่องการจัดหมวดหมู่สินค้าและ User Flow มาเป็นแรงบันดาลใจได้

หากระบบต้องเลือก Technology Stack ให้ใช้ Technology ที่เหมาะกับการทำเว็บไซต์ Production จริง และจัดโครงสร้าง Code ให้สามารถนำไปพัฒนาต่อได้ง่าย

ก่อนสร้าง ให้คิด Architecture และ User Flow ให้เรียบร้อย แล้วจึงสร้างเว็บไซต์

เป้าหมายสุดท้าย:
เมื่อลูกค้าเข้ามาเว็บไซต์ ต้องสามารถเห็นแบบบ้าน → เปรียบเทียบ → เลือกแบบ → คำนวณราคาโดยประมาณ → ส่งข้อมูลเพื่อสั่งจอง/ขอใบเสนอราคา ได้ภายในไม่กี่ขั้นตอน และเจ้าของเว็บไซต์สามารถบริหารสินค้าและ Lead จากหลังบ้านได้
